# よしかのひみつきち

下口慶夏の活動、制作物、価値観をまとめたReact製ポートフォリオサイトです。

- 公開サイト: https://ys-cocoa.github.io/web-programming/
- 使用技術: React / Vite / React Router / Formspree / GitHub Actions / GitHub Pages

## AI使用記録

本サイトの開発では、OpenAI Codexを次の用途で使用しました。

- Reactコンポーネントへの分割とデータ構造の整理
- PC・スマートフォン向けCSSの提案と調整
- マウス追従、カルーセル、作品フィルター、作品詳細モーダルの実装支援
- インタビュー内容から作品説明文を整理・推敲
- ビルド、Lint、PC・スマートフォン表示の確認

サイトのコンセプト、掲載作品、事実情報、文章の最終表現、デザイン上の判断は本人が決定し、AIの出力を確認・修正した上で採用しています。AIを使用した主要箇所には、ソースコード内にも`AI使用:`コメントを記載しています。
